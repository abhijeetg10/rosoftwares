# RO Softwares

> **You think it on paper. We build it with technology.**

Official website and digital showcase for **RO Softwares** — an agile product engineering team specializing in modern full-stack web platforms, high-concurrency event engines, and automated business management ecosystems.

---

## 🚀 Key Highlights & Projects Showcased

- **State-Level Digital Quiz & Live Evaluation Platform (Team Tameer)**
  - Real-time live stage arena and high-concurrency digital exam engine for 10,000+ simultaneous students across Maharashtra.
  - Interactive Buzzer Round console with timer and fastest-team selection.
  - Live tournament progression tree tracking 34 competing high schools from preliminary league to grand finals.
  - Zero downtime recorded with on-ground technical support.

- **RV Fitness — Complete Gym Web Platform & Management System**
  - Converted physical paper registries into an automated digital workflow.
  - Tiered membership plans (Monthly ₹1,500, Half-Yearly ₹7,500, Yearly ₹12,000).
  - WhatsApp renewal alerts and QR code attendance passes.

- **Engineering Leadership & Squad**
  - Led by **Rehan Chougle** (Senior Software Developer & Lead Architect).
  - Direct engineer-to-client communication without bureaucratic overhead.

---

## 🛠️ Tech Stack

- **Frontend:** Semantic HTML5, Vanilla CSS3 (Custom Design System with Dark & White/Light dual theme), Modern JavaScript (ES6+).
- **Backend & Event Ops:** Node.js, WebSockets / Socket.io, Redis In-Memory Caching, REST APIs.
- **Data & Cloud:** PostgreSQL, MongoDB, Cloud VPS Deployments, Nginx Reverse Proxy.

---

## 🌓 Features

- **Dual-Theme Engine:** Toggle between **Dark Mode** and **White/Light Mode** with `localStorage` persistence.
- **Interactive Project Galleries:** Live screenshot switchers and click-to-zoom Lightbox modal for case study previews.
- **Responsive Architecture:** Pixel-perfect rendering across mobile, tablet, and desktop viewports.

## 💻 Local Development

Simply open `index.html` in any modern web browser or serve via Live Server:

```bash
# Using Python built-in server
python -m http.server 3000

# Or open directly
start index.html
```
